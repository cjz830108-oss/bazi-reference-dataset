# BaZi / Chinese Metaphysics Reference Dataset

Deterministic, machine-readable reference tables for Chinese astrology (八字 / 紫微斗數) — generated by a calendar engine, **not hand-typed**, so every row is internally consistent and reproducible.

**Source & canonical version:** [yimingshu.net](https://yimingshu.net) — an Eastern-destiny tool for the overseas Chinese community. The same tables are browsable there with full explanations:

| Table | Online (Traditional Chinese) | JSON |
|---|---|---|
| 60 Sexagenary Terms (六十甲子) | [sexagenary-cycle](https://yimingshu.net/zh-hant/reference/sexagenary-cycle) | [data/sexagenary-cycle.json](data/sexagenary-cycle.json) |
| 2027 Monthly Pillars (丁未年) | [2027-monthly](https://yimingshu.net/zh-hant/reference/2027-monthly) | [data/monthly-pillars-2027.json](data/monthly-pillars-2027.json) |
| 12 Double-Hours (十二時辰) | [twelve-hours](https://yimingshu.net/zh-hant/reference/twelve-hours) | [data/twelve-hours.json](data/twelve-hours.json) |

If you use this data, a link back to the source page is appreciated — it is how this dataset stays discoverable and maintained.

## What's inside

### `sexagenary-cycle.json` — the 60 terms (60 rows)
Each pairing of one of the 10 heavenly stems (天干) with one of the 12 earthly branches (地支), with:
- the five element (五行) of both characters,
- the zodiac animal of the branch,
- the **Na Yin** (納音) sound and its element (two consecutive terms share one Na Yin).

Also includes lookup tables for the 10 stems, 12 branches, and the 30 Na Yin sounds.

### `monthly-pillars-2027.json` — 2027 Ding Wei (丁未) month pillars (12 rows)
The 12 month pillars (月柱) of the 2027 lunar year with Na Yin, zodiac branch, and the Gregorian date range each lunar month covers.

> **Note on correctness:** month pillars advance at a **solar term (節氣)**, not at the lunar month's first day — the new moon usually falls within a day or two of that boundary. Sampling the 1st of a lunar month mis-assigns the boundary months (for 2027 it yields 乙巳 twice). Each pillar here is sampled at lunar day 15, safely inside its term, so all 12 pillars are distinct.

### `twelve-hours.json` — the 12 double-hours (12 rows)
Clock-hour ranges, five element, zodiac animal, and the governing sexagenary term for each of 子時…亥時. 子時 spans 23:00–01:00 and crosses midnight (the traditional 23:00-start convention). This is the basis of the BaZi hour pillar (時柱).

## Generation

Data is produced by [tyme4ts](https://github.com/6tail/tyme4ts) (MIT), a deterministic Chinese-calendar engine — the same engine that powers the charts on yimingshu.net. To regenerate after a `tyme4ts` upgrade:

```bash
npm install
npx tsx scripts/export-dataset.ts   # writes datasets/bazi-reference-dataset/data/*.json
```

## Schema

Every file carries a `fields` block describing each key, plus `source`, `homepage`, `license`, and `generator` metadata. Dates are `YYYY-MM-DD` Gregorian.
